What keeps the NAS safe

Scan

A scan only reads the file list (names, sizes, dates) - gently, a few folders at a time, and it pauses while the editor is rendering. A big share takes hours: start it in the evening. "Full check" = scan + used-by-projects + unused report + duplicates.

Duplicate files

Same size and same content samples. Before anything moves, each copy is read in full and compared byte for byte with the copy that stays. The copy that stays: one a project uses, else one in a protected folder, else the oldest. Copies used by a project, in protected folders, or changed recently never move.

Unused and junk files

"Old" = not changed for days and not used by any editor / Premiere / After Effects project the scan found. Temp, cache (Media Cache, peak files...) and zero-byte files are junk the apps make again. Moved files go to the bin first and can be put back.

Organise a folder

Sorts the loose files at the top of one folder into sub-folders. You see the plan first; nothing moves until you press Apply, and the whole batch can be undone from the Bin & history tab. Files a project uses, and media next to a project file, stay where they are so no project loses its links.

Bin & history

Every clean-up and every organise is one batch here. "Put back" moves the files back where they were. Bin files stay on the NAS in _NAS Care Bin on the same share (no space is freed until a batch is emptied). Emptying is the only real delete, allowed only after the bin has kept it for the days set in Settings.
